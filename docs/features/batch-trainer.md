# Batch Trainer

Backtesting engine that simulates trades on historical data. Picks random moments, calls AI agents, simulates forward to TP/SL/timeout.

**File:** `src/batch_trainer.js`

**Data:** `data/eurusd_5m_oanda.json` (downloaded from OANDA API)

**Download data:** `node tools/download_oanda_data.js --months 6`
